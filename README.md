# Solar-System

## Overview

Solar system animation is a web project build using HTML, CSS, and JavaScript. It displays the sun and the 8 planets orbiting around it with smooth animations. Users can pause and resume the animation, adjust orbit speed and click planets to view information about them.

## Features 

1. Animated solar system.
2. Sun at the center.
3. 8 planets with individual orbits.
4. Twinkling stars background.
5. star/pause animation button.
6. Orbit speed control slider.
7. Planets information cards.
8. Responsive and simple desgin.

## Technologies Used

1. HTML5
2. CSS3
3. JavaScript

## How it works

The project uses css animations to rotate orbit paths around the the sun. Each planet is positioned on an orbit and moves as the orbit rotates. JavaScript is used to controls animations speed, pause and resume the movement, and display information when a planet is click.

## Usage

~ Click *Pause Animation* to stop planet movement.
~ Click *Start Animation* to continue movement.
~ Use the speed slider to change orbit speed.
~ Click any planet to view information about it.
